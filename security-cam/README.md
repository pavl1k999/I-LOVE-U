# Security Cam — один файл SecurityCam.exe

Программа включает веб-камеру при запуске ПК, записывает видео и транслирует его в браузер.

## Установка
1. Положите `SecurityCam.exe` в отдельную постоянную папку, например `C:\SecurityCam\`.
2. Запустите его двойным щелчком, нажмите «Да» и подтвердите права администратора.
3. Появится окно с адресом трансляции, логином и паролем. Их же можно найти в `config.ini`.

Готово: запись уже идёт и будет включаться при каждом запуске ПК, ещё до входа в Windows.
Видео сохраняется в папку `recordings\`. Файлы длиной по 10 минут, записи старше 7 дней удаляются.

**Удаление:** снова запустите `SecurityCam.exe` и выберите «Да».

## Трансляция
Откройте адрес, например `http://192.168.1.5:8080`, на телефоне или другом ПК в той же Wi-Fi-сети.
Если хотите смотреть из любого места, поставьте **Tailscale** на ПК и телефон.

## Telegram (можно подключить позже)
1. В Telegram откройте @BotFather, отправьте `/newbot` и получите токен. Затем нажмите Start в своём боте.
2. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`. Это ваш chat_id.
3. Впишите `token` и `chat_id` в `config.ini` и перезагрузите ПК.

После каждого включения ПК бот пришлёт **одно** сообщение «🔴 Трансляция началась» со ссылкой.

## Если не работает
- Параметры → Конфиденциальность → Камера: включите доступ для классических приложений.
- Сеть в Windows должна быть «Частной», иначе брандмауэр закроет трансляцию.
- Подробности смотрите в журнале `recordings\security_cam.log`.

Пока идёт запись, горит индикатор камеры. Используйте программу только на своём ПК.
Если компьютером пользуются другие люди, предупредите их о записи.

## Сборка exe
Собирается автоматически в GitHub Actions (workflow «Build SecurityCam.exe»).
Вручную: `pip install opencv-python pyinstaller` и затем
`pyinstaller --onefile --noconsole --name SecurityCam security_cam.py`.
