# Security Cam (Windows)

Включает веб-камеру **сразу при включении ПК** (ещё до входа в учётную запись)
и записывает видео в `recordings/`: файлы по 10 минут, с датой и временем на кадре.
Записи старше 7 дней удаляются автоматически.

## Установка
1. Установите Python 3 с https://www.python.org/ и отметьте **«Add python.exe to PATH»**.
2. Положите папку `security-cam` в постоянное место, например `C:\security-cam`.
3. Дважды щёлкните **`install.bat`** и подтвердите права администратора.
   Скрипт сам установит OpenCV, создаст задачу в Планировщике и сразу запустит запись.

Проверка: через минуту в `recordings\` должен появиться `.mp4`, а журнал будет в `recordings\security_cam.log`.

## Удаление
Дважды щёлкните **`uninstall.bat`**.

## Если не записывает
- **Параметры → Конфиденциальность → Камера**: включите «Доступ к камере» и
  «Разрешить классическим приложениям доступ к камере».
- Камера занята другой программой (Zoom, Teams, Discord): одновременно её может использовать только одна программа.
- Посмотрите `recordings\security_cam.log`.

## Как это работает
Задача «SecurityCam» в Планировщике заданий запускается от SYSTEM при включении ПК,
а также при входе в систему (на случай «быстрого запуска» Windows). Если скрипт упадёт,
он перезапустится через минуту. Если камера ещё не готова, скрипт подождёт её.

Настройки (камера, разрешение, FPS, длина файла, срок хранения) находятся в начале `security_cam.py`.

## Важно
Пока идёт запись, горит индикатор камеры. Используйте скрипт только на своём ПК.
Если компьютером пользуются другие люди, предупредите их о записи.
