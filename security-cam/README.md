# Security Cam — один файл SecurityCam.exe

Программа при запуске ПК включает веб-камеру и транслирует её онлайн.
**Видео на диск не записывается** — только живая трансляция в браузере.
Ссылка, логин и пароль приходят в Telegram.

## Установка
1. Положите `SecurityCam.exe` в отдельную постоянную папку, например `C:\SecurityCam\`.
2. Запустите его двойным щелчком, нажмите «Да» и подтвердите права администратора.
3. Появится окно с адресом трансляции, логином и паролем (они же — в `config.ini`).

Трансляция включается при каждом запуске ПК, ещё до входа в Windows.

**Удаление:** снова запустите `SecurityCam.exe` и выберите «Да».

## Telegram
После того как настроите бота (см. ниже), при каждом включении ПК придёт **одно** сообщение:
ссылка на трансляцию, логин и пароль.

1. В Telegram откройте @BotFather, отправьте `/newbot`, получите токен. Нажмите Start в своём боте.
2. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}` — это chat_id.
3. Впишите `token` и `chat_id` в `config.ini` и перезагрузите ПК.

## Как смотреть
Откройте ссылку из Telegram, например `http://192.168.1.5:8080`, на телефоне или другом ПК
**в той же Wi-Fi-сети** и войдите с логином и паролем.

Чтобы смотреть из любого места, поставьте бесплатный **Tailscale** на ПК и на телефон,
войдите под одним аккаунтом — тогда в сообщении будет и вторая ссылка «через Tailscale».

## Если не работает
- Параметры → Конфиденциальность → Камера: включите доступ для классических приложений.
- Сеть в Windows должна быть «Частной», иначе брандмауэр закроет трансляцию.
- Подробности — в журнале `security_cam.log` рядом с exe.

Пока идёт трансляция, горит индикатор камеры. Используйте программу только на своём ПК.
Если компьютером пользуются другие люди, предупредите их.

## Сборка exe
Собирается автоматически в GitHub Actions (workflow «Build SecurityCam.exe»).
Вручную: `pip install opencv-python pyinstaller` и затем
`pyinstaller --onefile --noconsole --name SecurityCam security_cam.py`.
