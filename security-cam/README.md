# Security Cam

Скрипт включает веб-камеру при запуске ПК и записывает видео в `recordings/`
(файлы по 10 минут, с датой/временем на кадре, записи старше 7 дней удаляются).

## Установка
1. Установите Python 3: https://www.python.org/ (на Windows отметьте «Add to PATH»).
2. `pip install opencv-python`
3. Проверка: `python security_cam.py` — должен появиться файл в `recordings/`. Ctrl+C — стоп.

## Автозапуск
**Windows:** Win+R → `shell:startup` → положите туда ярлык на `start_windows.bat`.

**Linux:** см. комментарии в `security-cam.service`.

**macOS:** при первом запуске разрешите доступ к камере для Терминала/Python
(Системные настройки → Конфиденциальность → Камера).

## Настройки
В начале `security_cam.py`: номер камеры, разрешение, FPS, длина файла,
срок хранения, задержка старта.

## Важно
Индикатор камеры будет гореть во время записи. Используйте только на своём ПК;
если компьютером пользуются другие люди — предупредите их о записи.
